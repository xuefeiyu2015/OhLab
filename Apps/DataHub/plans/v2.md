# Plan v2 — Single-neuron object vs location value analysis

## Goal
New batch script `Batch_ObjLocValue_SingleNeuron.m` that loads
`FEF_BothRA_StableValue.txt` or `SC_BothRA_StableValue.txt` (each result file
holds both `OutputData.StableValue` and `OutputData.OneDR`) and tests whether
object value and location value are carried by separate or shared RF neurons.
It also explains why the "other" value AUC is not flat in ObjOnly / LocOnly groups.

## Decisions made
- Reuse the existing per-neuron fields (`TgtAUC_RF`, `p_AUC_Tgt_RF_ranksum`,
  `AUCPSTH_TgtOn_Value_RF`, time vectors) from both DataStamps; do not recompute ROC.
- Same neuron selection as `Batch_ObjLocValue_Organize` (`Sel_All`), FEF and SC
  run separately, with Fast (ModuType 1) vs Others (ModuType 4) as subgroups.
- Computation and plotting are kept separate (`Compute*` = pure, `Plot*` = render only).
- Sign-align the "other" task by the significant task's sign (never by its own sign).

- Classification uses the fixed 100–200 ms scalar AUC only (decided 2026-11-05).
- "Coding" = ranksum p < 0.05. "No coding" is an option, `NoCodingCriterion`:
  - `'pvalue'` (default) — p >= 0.05
  - `'effect'` — |AUC-0.5| < `EffectMargin` (default 0.05)
  - `'both'`   — p >= 0.05 AND |AUC-0.5| < margin
  Neurons that are neither coding nor no-coding (e.g. p >= .05 but a large effect) → `Ambiguous`.
- Code layout: driver `Batch_ObjLocValue_SingleNeuron.m`; helpers in
  `BatchAnalysis/ObjLocSingleNeuron/` (separate files so they can be unit-tested).

[x] ObjOnly / LocOnly / Both / None from ranksum p; neurons with NaN p get an

### Step 3: Diagnostics for the "other value" AUC (compute functions)
[x] `ComputeSignConcordance` — within each group, the fraction with
    sign(AUC_obj-0.5) == sign(AUC_loc-0.5); binomial test vs 0.5.
[x] `ComputePreTargetAUC` — mean AUC in [-300, 0] ms per task per group
    (to test for the OneDR block-structure / anticipatory confound); signrank vs 0.5.
[x] `ComputeOtherValueEquivalence` — per group, mean |other AUC − 0.5| with
    bootstrap CI and a TOST against the equivalence margin.
[x] `ComputeSignAlignedAUC` + `ComputeGroupAUCTimecourse` — group-mean AUC time courses, other task
    aligned by the significant task's sign (port from Organize lines ~1026–1043).
